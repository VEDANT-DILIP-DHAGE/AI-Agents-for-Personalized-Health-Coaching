1. Introduction
1.1 Background & Motivation

Personalized wellness guidance spans multiple specialized disciplines: clinical nutrition, biomechanical exercise science, and circadian lifestyle recovery. Conventional single-agent conversational Large Language Models (LLMs) frequently struggle when deployed for comprehensive health advice due to three critical drawbacks: arithmetic inaccuracy in energy balance equations (BMR/TDEE), domain blending (e.g., treating diet and workout guidance with identical unstructured prompts), and hallucination of contradictory dietary advice.

To solve this challenge, this project implements a Collaborative Multi-Agent Generative AI Architecture. By uniting a deterministic scientific mathematics engine with domain-specialized agents (Nutrition, Fitness, Lifestyle) managed by a Lead Coordinator Agent, the framework delivers hyper-personalized, clinically coherent, and constraint-respecting wellness plans.

1.2 Problem Statement

Monolithic single-agent chatbot architectures exhibit critical limitations in automated health coaching:

  • Domain Hallucination & Formula Errors: Unspecialized LLMs struggle with multi-variable arithmetic, often miscalculating caloric deficits or macro splits.
  • Lack of Dietary & Biometric Grounding: General LLMs tend to ignore hard constraints (such as vegetarian/vegan restrictions, age limits, and metabolic baselines).
  • Single Point of Failure: Lack of resilient modular fallback mechanisms when cloud LLM endpoints encounter network delays or rate limits.
1.3 Objectives & Key Contributions

The core objectives achieved in this GenAI TAE 1 project are:

  1. Coordinator-Subagent Orchestration: Developed a modular Python OOP agent hierarchy that analyzes user intent and routes sub-queries to dedicated specialist agents.
  2. Deterministic-Stochastic Hybridization: Integrated exact physiological formulas (Mifflin-St Jeor equation, TDEE activity multipliers, BMI classification) to ground LLM reasoning in verified science.
  3. Dual-Engine LLM Fallback: Enabled zero-downtime execution supporting Google Gemini 2.5/1.5 Flash, Groq LLaMA-3, and an offline smart rule-based fallback generator.
  4. Interactive Clinical Dashboard: Designed a reactive Streamlit web interface featuring real-time biometric metrics, dynamic agent badges, and persistent JSON state.

2. Methodology
2.1 System Architecture & Pipeline

The system utilizes a Coordinator-Subagent Architecture. When a user submits an inquiry alongside profile metadata (Age, Gender, Height, Weight, Activity, Diet, Goal), execution proceeds through two coordinated stages:

Component Layer Module File Functional Responsibility
1. Deterministic Engine utils/health_calc.py Calculates exact BMI, BMR (Mifflin-St Jeor), TDEE, macro ratios, and water intake.
2. Master Coordinator agents/coordinator_agent.py Performs intent classification, dispatches sub-agents, and synthesizes final response.
3. Nutrition Specialist agents/nutrition_agent.py Generates meal plans (Veg/Vegan/Non-Veg), macro breakdowns, and nutrient timing.
4. Fitness Specialist agents/fitness_agent.py Builds progressive workout splits, sets/reps, warm-up, and recovery protocols.
5. Lifestyle Specialist agents/lifestyle_agent.py Formulates sleep hygiene, hydration protocols, and stress reduction habits.
6. State & Storage utils/storage.py Persistent JSON serialization for user profiles and multi-turn chat memory.
2.2 Deterministic Health Mathematics

To prevent stochastic math hallucinations, metabolic calculations are computed deterministically prior to prompt injection:

• BMI: weight (kg) / [height (m)]²  |  Categories: Underweight <18.5, Normal 18.5-24.9, Overweight 25-29.9, Obese ≥30
• BMR (Mifflin-St Jeor):
  Men:   BMR = (10 × weight_kg) + (6.25 × height_cm) - (5 × age) + 5
  Women: BMR = (10 × weight_kg) + (6.25 × height_cm) - (5 × age) - 161
• TDEE: BMR × Activity Multiplier [Sedentary: 1.2, Light: 1.375, Moderate: 1.55, Very Active: 1.725]
• Caloric Targets: Weight Loss = TDEE - 400 kcal (35% P / 40% C / 25% F) | Muscle Gain = TDEE + 300 kcal (30% P / 45% C / 25% F)
• Hydration: (weight_kg × 35ml) + Activity Bonus (0.25L - 0.75L)
2.3 Master Coordinator Routing & Prompt Engineering

The CoordinatorAgent inspects user queries for semantic tokens. Keywords related to food or diet activate the NutritionAgent; exercise and workout terms trigger the FitnessAgent; sleep, stress, or water queries activate the LifestyleAgent. Multi-faceted requests trigger all three sub-agents in parallel. System prompts enforce strict constraints, including dietary preference adherence, injury prevention, and mandatory safety disclaimers.

3. Result (Work Done)
3.1 System Implementation & User Interface

The full multi-agent application was implemented in Python using Streamlit with custom CSS Glassmorphism styling. Key interface capabilities include:

  • Real-Time Biometric Sidebar: Instant profile configuration (Age, Height, Weight, Activity, Diet, Goal) with live metric recalculation.
  • Biometric Status Dashboard: Visual metric cards displaying BMI category badge, BMR, TDEE, Target Daily Calories, and Hydration requirements.
  • Transparent Multi-Agent Chat Console: Displays distinct agent badges (🏷️ Nutrition Agent, 🏋️ Fitness Agent, 🌿 Lifestyle Agent) showing the contributing agents for every answer.
3.2 Case Study & Execution Trace
User Scenario: "22-year-old male, 70kg, 175cm, Moderately Active, Vegetarian, Goal: Build Lean Muscle."
Deterministic Computation: BMI = 22.9 (Normal) | BMR = 1,644 kcal | TDEE = 2,548 kcal | Target = 2,848 kcal/day (+300 surplus) | Macros: 214g Protein (30%), 320g Carbs (45%), 79g Fat (25%) | Water: 3.0 Liters/day.
Multi-Agent Collaborative Plan:
• Nutrition Agent: Structured 4-meal plan with Paneer, Tofu, Greek Yogurt, Dal, and Sprouts; timed post-workout nutrition within 45 mins.
• Fitness Agent: 4-day Hypertrophy Split (Push-ups/Bench, Squats, Rows, Shoulder Press, Plank) with 4 sets × 8-12 reps and 90s rest.
• Lifestyle Agent: 3.0L water schedule, 8-hour sleep protocol with 45-minute blue light cutoff, and 4-4-4-4 box breathing recovery.

3.4 Conclusion & Future Scope

The GenAI TAE 1 project validates that a hybrid multi-agent architecture outperforms traditional monolithic chatbots in specialized health domains. Decoupling knowledge domains into dedicated sub-agents and grounding their generation with deterministic physiological calculations eliminates mathematical hallucinations and ensures hyper-personalized recommendations.

Future Scope: Integration of multimodal computer vision for meal calorie scanning, wearable IoT smartwatch biometric synchronization, and reinforcement learning from human feedback (RLHF).
